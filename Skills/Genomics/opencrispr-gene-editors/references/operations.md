# OpenCRISPR Operations

## Released System

OpenCRISPR-1 was released on 2024-04-22. The official repository describes it as an AI-designed, RNA-programmable Cas9-like editor with an NGG PAM preference.

The release includes:

- the OpenCRISPR-1 protein sequence;
- a compatible AI-generated guide RNA;
- a HEK293T transfection protocol.

The repository states that canonical SpCas9 guide RNAs can be compatible and that the protein can be configured in deactivated or nickase forms for downstream editing modalities. Validate each configuration independently.

## Minimum Validation Panel

- on-target editing efficiency and product distribution;
- targeted and unbiased off-target testing appropriate to the application;
- large deletion, rearrangement, and translocation assessment when consequential;
- cell viability, growth, and stress response;
- delivery efficiency and editor expression;
- comparison with a validated reference editor;
- biological phenotype and rescue where applicable.
