# MCP Servers and Protocol Operations (2026)

This category covers both biomedical MCP servers and the protocol-level operating knowledge needed to run MCP safely.

## Flagship Skills

- `BioMCP/` - biomedical MCP entry point.
- `Biomed_Agent/` - biomedical MCP-connected agent workflows.
- `MCPmed/` - MCP adaptation for bioinformatics backends.
- `MCP_Operations_2026/` - protocol, registry, remote server, auth, approval, and security best practices.

## Curation Standard

- Prefer the official MCP docs, specification, registry, and SDK pages over community summaries.
- Include OpenAI and Anthropic integration guidance only when it clarifies protocol operations.
- Treat unofficial MCP server lists as discovery aids, not authoritative source material.
- Explicitly document approval, auth, egress, and logging requirements for any sensitive server.

## Practical Scope

Keep this folder focused on MCP as infrastructure: server design, client/server interoperability, transport choice, authorization, approval flows, and registry hygiene.
