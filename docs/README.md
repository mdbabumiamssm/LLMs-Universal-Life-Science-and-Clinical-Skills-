# Documentation Hub

This directory now mirrors the major facets of the BioOS stack so contributors
can quickly find the right design notes:

| Folder | Purpose | Typical Questions |
|--------|---------|-------------------|
| `architecture/` | High-level system maps, dependency graphs, and repo layout. | “How is the Skills tree organized?”, “Where do new agents plug in?” |
| `operations/` | Runbooks for multi-step workflows (dispatch flows, dashboards, reporting). | “How do I run the MedgeClaw stack end-to-end?” |
| `standards/` | Specifications (USDL, governance, security) referenced by multiple teams. | “Which USDL schema do we follow?”, “What’s the review checklist?” |
| `presentations/` | External decks and visual explainers. | “Do we have slides for exec briefings?” |
| `research/` | Whitepapers, validation studies, benchmarking notes. | “Where is the single-cell QC write-up?” |
| `strategy/` | Roadmaps and OKR trackers. | “What’s prioritized for Q2?” |

Each folder should keep a concise `README.md` or index so the intent stays
obvious, even as new documents are added.
