# Operational Runbooks

This section captures multi-step workflows that combine multiple skills (e.g.,
dispatch, dashboards, messaging). Keep runbooks concise with prerequisites,
step-by-step instructions, and validation checklists.

Available guides:

- `medgeclaw_stack.md` — canonical flow for dispatching bioinformatics tasks,
  keeping dashboards updated, and publishing Feishu briefings.

Want to add another runbook? Drop a Markdown file here and link it from
`docs/README.md`.
